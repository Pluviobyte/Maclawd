# 手工设计的候选动作

每个文件对应**一个动作**，导出该动作的若干个**真设计**候选
（不是 `scripts/build-variants.mjs` 那种参数化变体）。

## 为什么分文件

多个人/agent 同时改一个 `motion-poses.mjs` 必然冲突。一个动作一个文件，
互不相干，加载器把它们拼起来。

## 硬约束（这些不是风格偏好，是踩出来的）

1. **每个候选必须换掉一条不同的轴**，不能只换道具。
   已验证有效的轴：道具类型 / 构图 / 朝向 / 循环结构 / 对称性 / 场景。
   只换道具的那一批被判为「太类似」——四个看起来像一个东西的四种皮肤。

2. **持续态循环内不许有静止姿态，首尾姿态必须不同。**
   旧版 working 有 43% 的循环停在原位，且首尾同为原位——跨接缝后是
   连续 1.5 秒静止，读作「干一下停一下」。

3. **保持时长不许等分。** 等分 = 匀速 = 机械。变异系数要 ≥ 0.35。
   定格动画的缓动靠「极端姿势多停、中间姿势快过」表达。

4. **位移一律整数 px。** 主形态 135px ÷ 45 单位 = 3px/单位，非整数会让
   矩形边缘落在设备像素中间。

5. **躯干不许持续保持非 90° 倍数的倾斜。** crispEdges 下斜边会渲染成
   锯齿平行四边形。「垮掉」用下沉 + 纵向压缩表达，不要用小角度旋转。
   **90° 的整数倍是例外**——旋转后矩形仍然轴对齐，边缘照样干净，
   所以「侧倒」「翻过来」这类整圈姿态是合法的。

6. **爪子向左位移会脱离躯干。** 有道具时读作「伸手去够」，没道具可够时
   只读成断肢。

7. **道具不许遮脸。** 眼睛在 x4 与 x10、y8-10，脸是桌宠的身份。

8. **姿态密度 ≥ 2.8 /秒**（睡眠、低电量这类刻意慢的除外）。

9. **爪子落进躯干矩形里等于消失。** 爪与躯干同色 `#DE886D`、无描边，
   躯干占 x2–13 / y6–13。左爪位移 dx∈[2,11] 且 dy∈[-3,2] 会被整块吃掉。
   有道具时不要紧（道具替爪子表意），**没道具的动作必须全程把爪留在轮廓外**。

10. **道具不跟着身体走。** 道具组是 `.actor` 的兄弟节点，不继承身体的位移。
    要让道具「长在身上」（壳纹、背包一类），必须给它一条**复制身体位移**的
    动画，否则身体一动道具就留在原地。
    现存实例：`work-i-hunch.svg` 的 `.shell` 就没有自己的图层。

## 角色几何（契约，不可改）

```
viewBox  -15 -25 45 45          躯干  x2-13  y6-13
眼睛     x4 / x10  y8-10        爪    左 x0-2 右 x13-15  y9-11
腿       x3,5,9,11  y13-15      体色 #DE886D  眼色 #000000
```

## 文件格式

```js
export const CANDIDATES = [
  {
    action: 'idle',              // 对应哪个契约动作
    id: 'idle-c1',               // 唯一 id，用作 CSS state class
    title: 'Quiet Watch',        // 显示名
    axis: '构图 — 视线跟随光标',  // **这个候选换的是哪条轴**，必填
    desc: '一句话说明它在演什么',
    duration: 5600,
    props: '',                   // 画在角色身后的 SVG 片段（可选）
    propsAfter: '',              // 画在角色身前的（可选）
    splitLegs: false,            // 需要逐条驱动四条腿时设 true
    layers: [
      { sel: '.actor', name: 'idle-c1-body', poses: [['translateY(0)', 3], ['translateY(-1px)', 1]] },
      // sel 可用：.actor .left-claw .right-claw .eyes .blink
      //          .leg-a .leg-b .leg-c .leg-d（需 splitLegs）
      //          以及你在 props/propsAfter 里自己定义的 class
      // poses: [[transform 或完整声明, 权重], ...]
      // 可选 period（毫秒，让该图层走自己的周期）、origin（transform-origin）
    ],
  },
];
```
