体力 energy

1 − min(1, 今日吞吐 ÷ 过去 14 天中位数)。 体力越低，idle.drowsy 权重越高、away 静默阈值越短。 基线取个人中位数而非固定值，否则重度用户从早上就一直「疲劳」。

以 async 注册——Claude Code 不等 hook 返回，不会拖慢你的 agent。 只订阅状态事件；Bash 命令在写入器进程内就地分类， 命令原文永不离开该进程。安装会修改 ~/.claude/settings.json（先备份）， 卸载只移除自己写入的条目。

权限气泡 在桌宠上批准，默认关闭

通道关闭时，权限决策完全留在 Claude Code 自己的流程里。

超时一律「不表态」，绝不自动允许也绝不自动拒绝—— 桌宠没人看的时候，正确行为是把决策权原样交回去。
