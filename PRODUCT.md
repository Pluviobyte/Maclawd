# Product

## Register

product

## Users

Maclawd serves developers who use local AI coding tools such as Claude Code and Codex. They glance at the app while working to understand agent activity, subscription capacity, and local usage without leaving their current workflow.

## Product Purpose

Maclawd is a native macOS companion that turns local AI-tool activity into an immediately understandable pet, menu-bar summary, and compact control panel. Success means users can answer “what is my agent doing?” and “can I safely start more work?” in seconds, without learning implementation details or sending private usage data elsewhere.

## Brand Personality

Native, calm, and candid. Maclawd should feel companionable without becoming distracting, and technically trustworthy without exposing internal plumbing as product language.

## Anti-references

Avoid generic monitoring dashboards, alarm-heavy quota displays, dense developer diagnostics, unexplained mathematical symbols, and interfaces that make users reason about hooks, slots, chaining, or storage internals.

## Design Principles

1. Lead with the decision a user needs to make, not the mechanism that produced the data.
2. Distinguish exact values, estimates, lower bounds, stale values, and missing values in plain language.
3. Preserve native macOS interaction patterns and compact glanceability.
4. Keep configuration changes reversible and explain meaningful side effects before they happen.
5. Let the pet add warmth while data and controls remain quiet and precise.

## Accessibility & Inclusion

Follow native macOS accessibility behavior, including VoiceOver labels, system contrast, keyboard interaction, and reduced-motion preferences. Never rely on color alone to communicate quota state, freshness, warnings, or completion.
